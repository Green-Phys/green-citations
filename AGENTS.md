# Agent guidance

This repository is a scientific-credit authority. Never invent or infer a
citation mapping from a paper title, code path, or nearby documentation.

- Bibliographic metadata is owned by `CITATION.cff`.
- Citation policy and mappings are owned by `CITATIONS.yaml`.
- `CITATION.md` and `references.bib` are generated; do not edit them directly.
- Preserve `review-required` status until a collaborator explicitly approves
  the affected mapping.
- Validate DOI metadata against the publisher or Crossref before changing it.
- Run the generator, checks, and unit tests after every authority-file change.
